# Provenance and data notice

This is a new, independently authored implementation for the user's 3D segmentation workflow. It is inspired by the static-site / scheduled-discovery / editorial-review pattern of hongboduan/awesome-embodied-agents. It is not a fork of that repository, does not include that repository's source files, and is not affiliated with its author.

The initial 266 bibliographic groups were derived from the user's previously supplied Zotero export and organized snapshot. Only a sanitized bibliographic field allowlist is included. Original collection names, raw notes, annotation content, attachment paths, and raw export files are excluded. Wxxxx identifiers are preserved as snapshot identifiers, not Zotero keys.

Third-party paper metadata, titles, abstracts, logos, papers, figures, and external resources are not assigned the code license by this project. Confirm applicable terms before publishing third-party content. The optional PDF evidence-enrichment pipeline (page excerpts, verbatim quote verification with page numbers, unsupported-number rejection, and draft labeling) follows the design of hongboduan/awesome-embodied-agents (MIT License); no source files were copied. arXiv PDFs are downloaded into a local, gitignored cache only to extract page text for optional AI drafts; PDFs are never redistributed or published.

Local test Atom records are explicitly synthetic test fixtures, never inserted into production data. The shipped store begins with no online discovery success and no fabricated fresh papers.
